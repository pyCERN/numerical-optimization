# Numerical Optimization (Nocedal & Wright)

Python implementations of unconstrained optimization algorithms
following *Numerical Optimization* by Nocedal & Wright.

## Implemented
- Steepest descent with line search
- Test functions

## Dependencies
This project uses Eigen (header-only).

### Install Eigen
1. Download Eigen 3.4.x from https://libeigen.gitlab.io
2. Extract to:
   numerical_optimization/libs/eigen-5.0.0

### Build
make
